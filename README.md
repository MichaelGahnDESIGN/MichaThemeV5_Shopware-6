# MichaThemeV5 für Shopware 6

Theme von Michael Gahn DESIGN mit Hell-/Dunkelmodus, vielen Optionen und rechtssicherer Ausrichtung für DE und EU.

**Status:** in Entwicklung (Pre-Alpha).

## Funktionen

26 Free-Funktionen sind im Theme enthalten, 28 Pro-Funktionen werden per Lizenz freigeschaltet.
Die vollständige Liste mit Status steht in [`docs/FEATURES.md`](docs/FEATURES.md), offene Punkte in [`TODO.md`](TODO.md).

## Lizenz und Pro-Funktionen

Pro-Funktionen werden im MichaTheme V5 automatisch aktiviert, sobald eine gültige Lizenz (Abo oder Einzelkauf) für die Domain vorliegt. Die freien Themes enthalten nur die Free-Funktionen und verweisen für Pro-Funktionen auf https://theme.michael-gahn.de. Der Kauf erfordert zwingend ein Konto dort.
